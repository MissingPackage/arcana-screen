# ArcanaScreen user guide

## Start a screen

On first use, choose General, Combat or Blank, optionally name the screen, then create it. Existing users resume the last active screen automatically.

## Prepare

Prepare changes structure. Add a tool with its **Add** button or drag it into the layout. Open **Configure** on a tool to move it earlier/later, choose Compact/Standard/Wide or remove it. These controls are the keyboard and touch alternatives to drag-and-drop. **Undo layout change** restores the previous structural state.

## Run

Run protects the layout while keeping live controls active. Choose Narrative, Social, Exploration or Combat Focus. Quick Capture stores a name, decision or consequence; press `/` or `Ctrl/Cmd + Shift + K` to focus it. Dice and Timer remain in the utility dock.

## Save and recovery

Changes save to this browser automatically. **Data & recovery** can:

- check browser storage;
- export a portable JSON backup;
- preview and merge or replace from a backup;
- restore a recovery snapshot;
- export raw local data before a confirmed reset.

Keep exported backups in a location you control. Import never changes data before preview and confirmation.

## Accessibility and preferences

- Use Tab and Shift+Tab for every core control; a skip link appears on first Tab.
- All drag-dependent layout operations have visible button alternatives.
- Touch layouts use enlarged targets and the shell reflows at narrow widths and 200% zoom.
- Theme and reduced-motion preferences persist locally.

## Feedback

Open **Help and resources** in the header for the guide, privacy policy and feedback link. Avoid posting private campaign information in a public issue.
